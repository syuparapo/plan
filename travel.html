① 간사이공항에서 구입

휴대폰에 등록하지 않고 실물카드 그대로 사용. 카드가 섞이지 않도록 구분해 보관합니다.

② 엔화 현금으로 충전

  1. 역의 ICOCA 대응 충전기에서 언어·충전 메뉴 선택.

  3. 금액 선택 → 엔화 현금 투입 → 충전 완료 확인.
  4. 카드·잔돈을 챙김. 부족하면 1,000~2,000엔씩 추가.

  • 교토 일반 균일요금 시내버스: 보통 뒷문 승차, 앞문 하차하며 태그. 노선에 따라 승차 태그도 필요하므로 차내 안내 확인.
  • 란덴: 하차 시 차량 요금기 또는 역 개찰에서 결제. 환승 시 현장 안내에 따르기.
  • 잔액 부족: 다른 카드로 바꾸지 말고 충전·정산 후 같은 카드로 통과. 오류가 계속되면 역무원에게 문의.
  • 구매한 하루카·라피트: 승차권 포함 상품이면 그 티켓의 QR/종이표로 개찰. 동일 구간에 ICOCA를 추가 태그하지 않기. 승차권 포함 여부는 구매 내역 확인.
  • 잔액: 대응 편의점·상점에서 결제 가능. 마지막 날에는 과충전하지 않기.

말톡 이심 · 한국에서 설치

구매 완료. 주문 메일의 상품별 안내에서 지원 기종, 설치 권장 시점, 이용기간 시작 조건, 로밍·APN 설정을 먼저 확인합니다. 설치 즉시 기간이 시작되는 상품이라면 너무 일찍 설치하지 않습니다.

  1. 안정적인 Wi-Fi에서 주문 QR·수동 설치 코드를 준비. 서로의 화면에 QR을 띄워 스캔하거나 상품 안내의 사진 인식·수동 입력 방법 이용.
  2. 갤럭시: 설정 → 연결 → SIM 관리자 → eSIM 추가 → QR 코드 스캔. 메뉴는 기종·OS에 따라 다름.
  3. 아이폰: 설정 → 셀룰러 → eSIM 추가 → QR 코드 사용. 여행 회선 이름을 ‘일본 말톡’으로 지정.
  4. 설치 후 한국에서는 기본 데이터 회선을 한국 SIM으로 유지. 일본 회선은 상품 안내에 따라 도착 전까지 꺼둠.
  5. 설치 QR·주문번호·APN 안내·고객센터 링크를 오프라인 저장. 두 기기에 같은 QR을 중복 설치하지 않기.

일본 도착 · 갤럭시

  1. 비행기 모드 해제 → 설정 → 연결 → SIM 관리자.
  2. ‘일본 말톡’ eSIM을 켜고 모바일 데이터를 이 회선으로 선택.
  3. ‘데이터 전환’ 등 자동으로 한국 SIM 데이터를 쓰는 기능은 끔.
  4. 모바일 네트워크의 데이터 로밍은 구매한 말톡 상품 안내대로 설정. 켜야 하는 상품은 일본 회선이 데이터로 선택됐는지 먼저 확인.
  5. Wi-Fi를 잠깐 끄고 지도·웹페이지 연결 시험.

일본 도착 · 아이폰

  1. 비행기 모드 해제 → 설정 → 셀룰러 → ‘일본 말톡’ → 이 회선 켜기.
  2. 셀룰러 데이터를 일본 말톡으로 선택.
  3. 셀룰러 데이터 전환 허용 끄기.
  4. 한국 회선의 데이터 로밍 끄기. 일본 회선의 로밍은 해당 상품 안내에 따라 켜거나 끄기.
  5. Wi-Fi를 잠깐 끄고 지도·웹페이지 연결 시험.

연결이 안 되면 / 귀국하면

데이터 회선 선택 → 상품별 로밍·APN → 자동 네트워크 선택을 확인하고 비행기 모드를 잠깐 켰다 끄거나 재부팅합니다. 계속 안 되면 공항 Wi-Fi로 말톡에 문의. 여행 중 eSIM을 임의로 삭제하지 않습니다. 재설치가 제한될 수 있습니다.

한국 번호로 문자 수신이 필요하면 한국 회선을 유지하되 데이터 로밍은 끕니다. 전화 발신·수신은 통신사 로밍 요금이 별도로 생길 수 있습니다. 귀국 후 모바일 데이터를 한국 회선으로 돌리고 일본 회선을 끕니다.
